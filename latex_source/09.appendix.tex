\section*{Appendix A: Artifact Availability}
\addcontentsline{toc}{section}{Appendix A}

All code, data manifests, experiment artifacts, and the LaTeX source of this
report are available at
\url{https://github.com/TaliesinYang/vllm-ltr-optimization}, with the report
sources under the top-level \texttt{latex\_source/} directory and every figure
script under \texttt{scripts/}. Each quantitative claim in this paper traces to
a committed JSON artifact through \texttt{EVIDENCE-MAP.md}, which is generated
rather than written: its builder reads every value out of the artifact it names
and fails if that artifact disagrees with the number printed here.
